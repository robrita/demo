# POL-2024-001: Fee Waiver and Reversal Policy

## 1. Purpose

This policy defines the authority levels, conditions, and procedures for waiving or reversing bank fees and charges for retail and SME customers.

## 2. Scope

Applies to all branch staff, contact center agents, relationship managers, and back-office operations personnel authorized to process fee adjustments.

## 3. Fee Waiver Authority Matrix

| Role | Maximum Waiver per Transaction | Maximum Waiver per Month (per Customer) | Requires Supervisor Approval |
|---|---:|---:|---|
| Teller / Service Associate | PHP 500 | PHP 1,000 | No |
| Branch Operations Officer | PHP 2,000 | PHP 5,000 | No |
| Branch Manager | PHP 10,000 | PHP 25,000 | No |
| Area Manager | PHP 50,000 | PHP 100,000 | Division Head sign-off |
| Division Head or above | Unlimited | Unlimited | Board-level reporting for > PHP 500,000 |

## 4. Conditions for Fee Waiver

4.1 Fee waivers may be granted when:

- (a) The fee was assessed due to a bank system error or processing delay.
- (b) The customer has a documented complaint and the fee is a contributing factor.
- (c) The customer qualifies for a promotional fee waiver program.
- (d) The customer is a preferred or priority banking client and the waiver is within the RM's retention budget.
- (e) Regulatory or ombudsman direction requires reversal.

4.2 Fee waivers must NOT be granted when:

- (a) The customer requests a waiver for a fee that was properly disclosed and agreed upon at account opening.
- (b) The waiver is being used to circumvent pricing policy.
- (c) Granting the waiver would set a precedent that conflicts with published fee schedules.

## 5. Procedure

### 5.1 Standard Fee Waiver Request

1. Customer requests fee waiver at branch or via contact center.
2. Staff verifies the fee in the transaction history system.
3. Staff checks authority level per Section 3 matrix.
4. If within authority, staff processes the reversal in the core banking system using Transaction Code FW-01.
5. Staff documents the reason using the Fee Waiver Reason Code (see Appendix A).
6. Confirmation receipt is provided to the customer.

### 5.2 Escalated Fee Waiver

1. If the amount exceeds the staff member's authority, a Fee Waiver Request Form (FWRF-01) is submitted via the internal workflow system.
2. The approver reviews the request within 2 business days.
3. If approved, the approver processes or authorizes the reversal.
4. If declined, the branch contacts the customer with the decision and alternative options.

### 5.3 Delegation of Authority During Absence

1. When an approver is on leave, their fee waiver authority may be delegated to an authorized acting officer at the same or higher level.
2. Delegation must be documented in writing (email or memo) before the absence period begins and recorded in the Branch Delegation Register.
3. Acting officers may only exercise delegated authority for the duration specified in the delegation notice.
4. An Area Manager may approve fee waivers delegated from a Branch Manager without requiring additional sign-off, provided the amount is within the Branch Manager's original authority (PHP 10,000 per transaction, PHP 25,000 per month per customer).
5. If no acting officer is designated, the request must be escalated to the next higher authority level.
6. Delegated approvals must reference the delegation memo number in the Fee Waiver Register.

## 6. Documentation Requirements

- All fee waivers must be logged in the Fee Waiver Register (system-generated).
- Waivers above PHP 10,000 require a scanned copy of the FWRF-01 form.
- Monthly fee waiver reports are submitted to Risk and Compliance by the 5th business day of each month.

## 7. Monitoring and Reporting

- Branch Ops reviews fee waiver patterns monthly.
- Internal Audit may sample fee waivers quarterly.
- Unusual patterns (e.g., same customer receiving repeated waivers) are flagged for review.

## Appendix A: Fee Waiver Reason Codes

| Code | Description |
|---|---|
| FW-SYS | System error or processing delay |
| FW-CMP | Customer complaint resolution |
| FW-PRO | Promotional program |
| FW-RET | Customer retention (RM approved) |
| FW-REG | Regulatory or ombudsman direction |
| FW-OTH | Other (requires narrative) |
